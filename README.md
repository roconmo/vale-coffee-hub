# Vale Coffee Hub - propuestas de web

Tres propuestas de web para Vale Coffee Hub (C. de Ginzo de Limia, 42, Madrid).

- `index.html`: página de inicio para elegir propuesta.
- `vale-luz.html`: estilo minimal y luminoso.
- `vale-obrador.html`: estilo cálido, centrado en desayunos y meriendas.
- `vale-pop.html`: estilo con color, con las tartas como protagonistas.

Cada página es un único archivo con las imágenes incluidas. Se publica con GitHub Pages.
